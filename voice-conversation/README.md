# 好侍达 · 语音对话

独立手机端交互原型，沿用「司导端汇报版-2610」的品牌色、Ambient 渐变背景、语音球、Phosphor 图标、圆角与间距。目标尺寸为 390×844，并适配较小手机和桌面预览。

页面背景沿用用户参考图的顶部蓝紫、底部粉橙与蓝紫配色，以容器比例定位的大范围CSS径向渐变呈现更轻、更开阔的弥散效果；中部保留柔白，底部保持透明。原参考图保存在dist/assets/voice-background.png。

运行 `npm start` 后访问 http://127.0.0.1:5186 。无需安装依赖或构建。`npm run check` 检查脚本语法，`npm test` 验证流程、语音选择口令、匹配时间和取消重置。

点击光球或「开始对话」后，固定剧情自动展示「10:30 洗猫」→「您需要上门，还是送去宠物店？」→「送去宠物店」。AI 通过浏览器 SpeechSynthesis 播报，必要时展示单程送猫 28 元与全程接送 200 元的方案卡。两者均不含洗猫费用。地址与店铺为预设示例。

演示完全按固定剧情运行，不申请麦克风，也不使用实时语音识别。用户说话由预设剧情和动效模拟；AI 通过语音播报，主界面只在需要选择或确认时显示卡片。点击方案卡可选择单程或全程接送；点击「语音选择」会模拟用户选择全程接送，也可使用文字输入。

AI播报完接送方案后才开始计时，随后5秒内没有选择，会自动选择第一种单程送猫28元并开始派单；播报过程中也可手动选择，手动选择或开始模拟语音选择会取消默认选择。暂停期间不计时，恢复后继续剩余时间；若打断了方案播报，则等恢复并播报完后再计5秒。挂断会清除计时，取消订单重新展示方案时重新计5秒。

匹配按寻找、通知和确认阶段自动推进，自选择方案起约 10 秒后出现模拟接单结果。支持取消匹配重新选择、查看订单、模拟联系司机、文字输入、查看对话记录、关闭播报和重新开始。

所有订单、司机、地址、价格与接单结果均为本地演示，不调用真实订单、支付、电话或 AI 服务。AI 播报使用浏览器提供的声音，剧情推进不依赖录音或语音识别。无音频录制、文件保存或本机存储；刷新恢复初始状态。

语音页面名称为「好侍达」，首页文案为「有事儿您说话」。默认状态与无卡片对话状态共用同一光球位置：以大尺寸在居中位置上移32px显示（矮屏上移24px）；出现预约方案或司机卡时才缩小上移，卡片消失后回到居中偏上的位置。对话字幕隐藏，保留正在听/正在回答等状态，完整会话可从「更多 → 对话记录」查看。预约卡采用「服务预约」标题，展示凤凰城至四月宠物医院、服务内容与预估费用。

首页标题统一使用 20px，默认状态隐藏球底语音图标。光球根据卡片是否显示，以720ms过渡切换位置和尺寸，波形与状态同步跟随；卡片上移时延迟350ms后用320ms淡入，消失时先用250ms淡出，再让光球回中。矮屏通过容器变量压缩尺寸与间距。系统开启「减弱动态效果」时关闭过渡及循环动画。

等待、用户说话、AI回答和打断通过语音球、波形及正在听/正在回答等状态反馈，用户和AI的对话字幕继续隐藏。点击光球或状态区会暂停当前剧情，再点击同一个位置即可继续；底部按钮也支持继续。暂停期间不会自动进入下一轮；匹配期间的暂停时间不计入约 10 秒的演示时长。用户说话和 AI 回答分别显示对应动效。退出、重置或离开页面会清理剧情计时器并停止播报。

默认页底部仅显示居中语音按钮；开始对话后左右分别显示播报开关和红色挂断按钮。挂断会停止播报与剧情、清空当前演示并回到默认页。文字输入可从「更多 → 文字对话」进入。

默认语音按钮视觉直径为84px，开始后600ms内缩回64px，两侧按钮延迟120ms后淡入；窄屏与矮屏按当前56px控制尺寸等比例放大。底部按钮整体上移12px，底部指示条保持原位；按钮缩放时中心保持固定，系统开启减弱动态效果时直接切换。

预约及司机卡以「司导端汇报版-2610」当前任务卡规范为基础：16px圆角、36px磨砂模糊、无描边与柔和阴影，淡紫色标题区配半透明内容层，标题复用钉钉进步体；横向内边距16px，纵向按紧凑语音卡片使用8/12/16px间距。配色与金额沿用主色及价格强调色，背景和语音球保持现有设置。派单期间展示居中偏上的语音球、语音状态及正在寻找司机/正在通知司机/司机正在确认行程等动态提示，「取消订单」位于更多菜单；接单后可从头像行右侧的电话图标模拟联系司机，订单详情可通过文字对话查看。费用说明仅在订单详情展示，方案语音仅播报服务与预估价格。司机及通话弹窗头像复用2610项目的现有人像素材，电话按钮与星级评分统一使用品牌主色。

语音球边缘近白色保持环形遮罩与缓慢流动，峰值停留延长至周期的20%—60%，淡出结束推迟至85%。

卡片样式来源为参考项目的dist/styles/tokens.css、task-reference.css、task-timeline.css；本地dist/tokens.css集中维护复用的表面参数。短屏保持卡片区独立滚动，并预留阴影空间，底部控制区固定。

语音球使用蓝色、紫色与薄荷色流动层：每个色块保留10%—12%的实色中心，向外依次过渡到同色系的中间色和浅色，再渐隐融入相邻颜色。球体不旋转，球内颜色的位置和面积按12/16秒周期变化；没有中心Ai标记、固定白色描边或环形外光圈，仅保留原有边缘近白色的缓慢流动。状态波形和720ms缩放位移保持。

两张服务预约卡的标题在所有尺寸下统一18px、26px行高，使用正文深色；司机接单标题为18px、32px行高。底部圆形控制使用56px模糊和170%饱和度的毛玻璃，叠加92%至66%不透明度的纯白渐变，保留默认放大与对话态缩小。预约及司机卡共用连续的浅紫色底层，标题区透明，避免矩形背景在下层内容的16px圆角两侧露出直角；双层阴影降低至12%及6%浓度，Y轴偏移减至4px及1px，保留负扩散值，让阴影更轻、更均匀。卡片区填满底栏上方剩余空间，顶部28px和额外64px底部留白容纳阴影，顶部负边距保持原卡片位置，减轻阴影截断的水平硬边；短屏仍可独立滚动。

司机卡内容按“贵A·D2688 ·白色 → 比亚迪秦 PLUS → 陈师傅与评分 → 行程与费用”展示；车牌和颜色均为20px并统一为正文深色，车牌加粗，车型独立第二行，司机姓名14px、头像36px。标题区不显示到达时间标签，联系按钮保持44px触控尺寸。预约与司机卡移除外描边、内侧边缘高光及内容层顶部高光线，保留16px圆角与柔和阴影。
